
# Job Offers Web Scraping 📊

A Python-based web scraping project designed to collect, extract, and organize job offer information from online recruitment websites.

## 🎯 Project Overview

This project explores how web scraping can automate the collection of job-related information and transform web data into structured datasets for further analysis.

It is part of my interest in Python, data engineering, and data science.

## ✨ Features

- Automated extraction of job offer information
- Collection and organization of job-related data
- HTML page parsing and data extraction
- Data cleaning and preprocessing
- Structured output for further analysis
- Export of collected data to CSV when configured in the notebook

## 🛠️ Technologies

- **Python** — Core programming language
- **Jupyter Notebook** — Interactive development and experimentation
- **BeautifulSoup** — HTML parsing and information extraction
- **Selenium** — Browser automation for dynamic web pages
- **Pandas** — Data manipulation and organization

## 📁 Project Structure

```text
job-offers-web-scraping/
└── job_offers_web_scraping.ipynb
```

The Jupyter Notebook contains the scraping workflow and related Python code.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Oumaimamosbehi/job-offers-web-scraping.git
cd job-offers-web-scraping
```

### 2. Install the dependencies

```bash
pip install jupyter pandas beautifulsoup4 selenium
```

Depending on the notebook implementation, additional libraries or browser-driver configuration may be required.

### 3. Run the notebook

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open the `.ipynb` file and run the cells in order.
